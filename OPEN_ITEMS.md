# Open items inbox

One line per item, appended by Claude Code sessions. The weekday evening sweep moves each line into the Open Items artifact and then clears this file. Only append below the marker.

Format (pipe-separated, one line each):

    YYYY-MM-DD | Owner | What is owed, in one sentence | optional source (file path, ticker, or link)

Owner is one of: Riley, Claude Code, Engineer, External. Use `Done` as the owner to close an item already on the list.
